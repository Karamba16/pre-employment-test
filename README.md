1) Cкачивания файла python_analyze.py
2) Запуск командой
   **python python_analyze --files {путь к файлу/ пути к файлам}**(какие файлы будет обрабатывать) **--report {название}** (сохраняет в файл с таким названием + .csv в месте, где расположен файт программы)
